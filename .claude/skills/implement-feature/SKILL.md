# Implement Feature

Follow this workflow:

1. Understand the requirement.
2. Inspect the existing architecture. If none exists yet (empty project),
   use the architect agent to propose the initial bootstrap first — see
   the project-structure rule for the required directory layout.
3. Identify affected files.
4. Identify business rules.
5. Identify authorization requirements.
6. Identify database changes.
7. Implement the smallest coherent solution.
8. Add or update tests.
9. Run relevant tests.
10. Inspect the final diff.

Do not perform unrelated refactoring.

Do not claim success without verification.
