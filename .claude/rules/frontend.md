# Frontend Rules

- Prefer simple and accessible interfaces.
- Use semantic HTML.
- Keep JavaScript focused on browser behavior.
- Keep business rules on the server.
- The server remains authoritative.
- Do not introduce a frontend framework without a clear reason.
- Keep visual patterns consistent.
- Avoid unnecessary animations.
- Avoid duplicated CSS.
- Provide clear loading states.
- Provide clear validation feedback.
- Provide clear error states.
- Provide useful empty states.
- Never expose sensitive information in the browser.
- Prioritize usability over visual complexity.
